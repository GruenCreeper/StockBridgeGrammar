# StockBridgeGrammar 1.0.0 示例说明

这个目录提供造桥线框脚本、生成 GH 画布的脚本、库存 JSON、19 条规则参数例子和[连线表](connection_map.md)。运行脚本或按表手动连线即可建立示例。

## 使用步骤

1. 按[主说明](../../使用说明_中文.md)安装插件。
2. 把 Rhino 8 文档单位设为米，再运行 `create_demo_truss_rhino.py`，得到约 12 米跨、1.6 米高的 Warren 桁架。
3. 在新 GH 画布放 GhPython/Python 组件，添加布尔输入 Run，粘贴 `build_demo_canvas.py`，Run 设 true 生成组件。它使用插件 15 类组件中的基本工作流子集。
4. 生成后把 Run 改 false。Curve 参数选择所有示例杆线。若脚本报告某些连接失败，按 connection_map.md 检查修复；不同 Rhino Python 运行时的行为可能不同。
5. Example Stock 选择 `short_stock`。Recognize.Report 显示节点合并和杆件数量；Assign.M 显示库存不匹配。图不输出弦杆角色或节间分类，Rhino 图层名称只用于例子组织。
6. 默认规则是 `splitMemberByStockLength`，使用默认参数。库存已经同时接 Assign.S 和 **Apply.S**。查看 Apply.H/W，确认目标是否适用以及补连支撑的结果。
7. Decode 查看结果；Candidate Selector 可直接读取 Generate 的整棵候选树，切换索引并查看实际名称和历史。

连续改写要传递更新后的图。逐杆建议列表不等于依次应用所有建议。

## 空间加点

运行[三锚点、三根 2 米料例子](../add_node_spatial/README.md)，可以直接验证上下镜像和原长。**Apply.Position 接三个锚点，Apply.Target Point 接期望新点**。**Target Picker.Tp → Apply.Tp** 传递期望点的原始坐标；T 输出只包含节点或杆件 ID。

## 其他示例

`../build_section_loop_canvas.py` 构建单次 Section Check → Apply 流程，正确使用 **G2/Nr/Nt → G/R/T**。修改结构后先重新求轴力再检查；若建议规则需要锚点或目标点，还需补齐输入。

插件输出几何、库存与部分拓扑诊断，不能用这些输出代替整体稳定性分析。
